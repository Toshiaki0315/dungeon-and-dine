# コンセプト＆ストーリー設定：『Dungeon & Dine: 飢餓のトレジャーハンター』（仮題）

> 開発仕様書 `game_specification.md` の別紙（リポジトリ: `dungeon-and-dine`）。実装上の判断は仕様書を優先する。

## 1. コアコンセプト
**「食うか、食われるか。極限状態のダンジョンサバイバル・ハクスラ」**

本作は、ターン制・グリッド移動の王道ローグライクRPGに、「モンスターを調理して食いつなぐ」というサバイバル要素を組み合わせた作品である。

面白さの軸は次の2つ。
- **リソース管理:** インベントリの容量、食糧、鑑定・解呪アイテムをやりくりする。
- **ギャンブル性:** 正体不明のアイテムや食材を、リスクを承知で使う。

## 2. ストーリー（あらすじ）
主人公は、一攫千金を夢見て未踏の遺跡「奈落の迷宮」に挑んだ新米トレジャーハンター。迷宮の最深部（地下20階）には伝説の財宝が眠ると言われている。

探索を始めてすぐ、主人公は崩落の罠にかかり、地上への退路を断たれてしまう。持っていた数日分の食糧はすぐに尽きた。空腹で倒れそうになったとき、目の前には倒したばかりの魔物が転がっていた。

「……背に腹は代えられない」

生き残るため、そして財宝を手に入れて生還するため、ハンターは魔物を解体し、焚き火で肉を焼いた。最初は吐き気をもよおす味だった。しかし、迷宮に散らばる「先人のメモ」を読み解き、試行錯誤を重ねるうちに、魔物料理は力の源に変わっていく。

こうして、モンスターを喰らい、未知の武具を現地で調達しながら最深部を目指す、前代未聞の「美食と強欲のサバイバル」が始まった。

最深部には、迷宮そのものの飢えを体現する主「奈落の大喰らい」が待ち受けている。

### 拠点（ベースキャンプ）の位置づけ
崩落した通路の下には、かつて同じように閉じ込められた先人たちが築いた地下キャンプがある。そこには商人や鑑定士などが住みついている。

- 力尽きたハンターは、キャンプの住人に救助されて目を覚ます。ただし、持ち物はすべて迷宮に置き去りになる。
- 手帳に書き留めたレシピの知識だけは失われない。

## 3. キャラクター
**主人公（プレイヤー）: レオ**
- 職業: トレジャーハンター
- 動機: 借金の返済と一攫千金
- 外見: 茶色の髪、革の鎧に緑のスカーフ、手斧を背負う（参考画像 `cooking_cutin_concept.jpg`）。
- 特徴:
  - しぶとく、生き汚い。
  - 最初は嫌々モンスターを食べているが、次第に未知の食材への探求心（あるいは狂気）に目覚めていく。

**ベースキャンプの住人**
- 道具屋、鑑定士、解呪を行う元神官など。先人の生き残りやその子孫。

## 4. 世界観とアートスタイル
- **ビジュアル:** Pyxel の16色パレットによるピクセルアート。温かみと少しの不気味さが同居する、レトロな雰囲気。
- **探索画面:**
  - 8×8 px の小さなタイルで描く、シンプルなドット絵にする。真上からの見下ろし。
  - レオ、モンスター、宝箱、罠、床、壁などを、すべてドット絵で描く。ASCII文字による表示（本家ローグの `@` や `#` など）は使わない。
  - 状況がひと目で分かるローグらしい画面にする。
- **料理カットイン:**
  - 調理のときだけ、描き込んだ1枚絵の画面に切り替わる。
  - 参考画像 `cooking_cutin_concept.jpg` は、B4F「苔むす洞窟」でレオが焚き火で魔物の肉を焼く場面。苔と光るキノコ、揺れる松明、緑を基調にした湿った空気感を持つ。
  - 普段のシンプルな画面とのギャップで、「食事の時間」を特別な見せ場にする。
- **エリア:** 苔むす洞窟 → 骸骨の地下墓地 → 灼熱の坑道 → 影の深淵 → 奈落の底。深く潜るほど、色調が暗く、禍々しくなる。
- **演出:**
  - 料理: おいしそうな湯気のアニメーション。
  - 呪われた装備: 身につけたときの、おどろおどろしいエフェクト。
